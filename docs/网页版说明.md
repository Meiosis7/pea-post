# 豌豆邮局 · 第二版

用现代浏览器打开 `豌豆邮局.html`，即可离线游玩，无需安装或联网。

## 玩法
- 四季来信：16 封递进委托，预测与搭配亲本，收藏 48 星。
- 育种温室：跨代留种、出售收获、6 份订单、两级扩建、9 种基因型图鉴与谱系。
- 配子工坊：亲手组装 3 种亲本的所有配子。
- 自由实验：16 / 64 / 256 颗首批样本、可追加抽样、可点击的配子棋盘和种子点阵。
- 实验档案与 8 项荣誉；成绩自动保存；设置中可导出、导入完整存档。

第一版的八关成绩会自动迁移。旧版没有记录实验次数和样本历史，因此这两项从升级后的新实验开始累计。存档不跨浏览器自动同步。

快捷键：1 / 2 选亲本槽，M 开关音效，? 查看帮助。卡片既可点击，也可拖动至亲本槽。手机底部按钮可以跳到下一步。

## 开发验证
`npm test`：遗传引擎、扩展关卡、温室经济与存档 36 项测试。
`npm run build`：把全部插画、样式和逻辑打包到独立 HTML。
`npm run serve`：在本机 64312 端口运行 dist（端口空闲时）。
`npm run test:browser`：实际 Chromium 交互测试；浏览器路径配置位于测试文件中，默认 macOS Google Chrome。

完整验证见 artifacts/final-evidence.md。来源文件位于此目录，sources/ 未作修改。
